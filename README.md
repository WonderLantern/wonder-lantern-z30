# Wonder Lantern Z30

**简体中文** · [English](README.en.md)

Wonder Lantern Z30 是 WonderLantern 组织面向 **Nikon Z30 C 1.20** 的固件扩展项目，探索类似 Magic Lantern 的机身端扩展能力。它是 Z30 专用项目，不是通用的跨机型框架，也不代表 Nikon 支持或认可。

**新功能从存储卡上的补丁文件加载。** 相机里只需刷一次**加载器固件**；之后添加、去掉或更新功能，都只是换卡上的 `Z30/WL.PATCH`，不用再刷机。只有加载器本身有底层更新时，才需要再刷一次加载器（打包工具会明确提示）。

> [!TIP]
> ### 📖 [图形界面打包教程（图文）→](docs/gui-tutorial.md)
> 第一次使用？跟着教程一步步完成：下载打包程序 → 校验原厂固件 → 打包并刷入加载器 → 打包功能卡文件并放到存储卡。

> [!WARNING]
> 修改固件有风险。刷入加载器前请确认：
> - 保留未经修改的 `Z_30_0120.bin`；
> - 知道如何通过 **设定菜单 → 固件版本** 重新升级。
>
> 只要能进入升级页面，就能刷回原厂固件；项目交付的每个加载器固件都会先检查这一点。卡文件出问题时，拔卡或换文件重启即可恢复，不需要重刷。打包程序本身不连接相机，也不写 SD 卡。

## 工作方式

| 部分 | 放在哪里 | 内容 |
| --- | --- | --- |
| 加载器固件 `EG209020.BIN` | 刷进相机，**只需一次** | 原厂固件、带常用字的中文字体（GB2312 一级字、Big5 常用字）和一个加载器。不插卡时与原厂一致 |
| 功能卡文件 `Z30/WL.PATCH` | 存储卡 | 所选功能的代码和补丁。开机约 3 秒后由加载器读入内存，功能随即出现 |
| 加载日志 `Z30/WL.LOG` | 存储卡（加载器写入） | 一行结果，`S=01` 表示加载成功 |

- **换功能只换卡文件：** 在打包工具里重新勾选功能，生成新的 `WL.PATCH` 复制到卡上，重启即可。
- **什么时候要重刷加载器：** 卡文件按相机上那份加载器构建。只有新的卡文件用到这份加载器不具备的能力（例如新的卡文件格式），或用到它的字体里没有的字时，打包工具才会拒绝生成并提示更新加载器。平常添加功能或更新版本都不需要。
- **安全检查：** 加载器写入前会检查卡文件的 CRC、加载器身份和每处原字节，任何一项不符都不改动相机内存，相机保持原厂行为。
- **加载提示：** 加载成功后，照片取景上方显示约 2 秒“Wonder Lantern 已就绪 · 16 项功能”，扩展菜单的“状态”页显示卡文件是否加载、版本和功能数。

原理、日志代码和实机记录见 [SD 卡加载说明](docs/card-loader.md)。

## 功能一览

`full` 包含下表全部十六项功能，也可以单独选择或任意组合。画幅、斑马纹、码率、日期水印、竖拍显示、NEF 压缩菜单、陀螺仪电子防抖、3D 跟踪和对焦框颜色会自动带上扩展菜单框架；菜单框架不再依赖快门声音，不选 `shutter-sound` 时不包含声音功能。

| 预设 | 功能 | 说明 |
| --- | --- | --- |
| `liveview-dual` | 在水平仪页后新增“顶部信息＋直方图＋水平仪”全信息 DISP 页 | [文档](docs/liveview-full-info.md) |
| `shutter-sound` | 从 SD 卡读取自定义电子快门声音，可开关、选择文件、预听、重新加载 | [文档](docs/shutter-sound.md) |
| `m900` | 启用原厂已有的 M 档长曝光路径，最长 900 秒 | — |
| `mtp-fast` | 加速 MTP 属性列表查询，返回数据不变 | [验证](docs/verification.md) |
| `video-rot` | 为新录像写入方向元数据，锁定开始录制时的方向 | [文档](docs/video-rotation.md) |
| `bitrate-slowmo-uncap` | 机内三档码率并记忆，提高 4K/1080p 高画质码率；慢动作录制上限延长到 25 分钟 | [文档](docs/bitrate-slowmo-uncap.md) |
| `aspect-profiles` | 六种照片比例，带半透明取景遮幅，保留原厂网格 | [文档](docs/aspect-profiles.md) |
| `photo-zebra` | 把原厂斑马纹扩展到照片取景，独立开关 | [文档](docs/photo-zebra.md) |
| `wifi-5ghz` | 全部有效无线配置请求 US/-1 国家码，解锁 5 GHz 连接 | 见注¹ |
| `date-stamp` | JPEG 右下角的胶片风格日期水印，五种格式、四种颜色、可选光晕，随竖拍转向 | [文档](docs/date-stamp.md) |
| `portrait-ui` | 竖拿时照片取景信息和 i 菜单改为竖版，转动后自动补全，默认关闭；触摸跟着竖版位置，i 菜单设置页按 2/3 竖版显示；快门、光圈、ISO 滑条页竖版；直方图页竖拿时显示竖版直方图 | [文档](docs/portrait-ui.md) |
| `nef-menu` | 在扩展菜单里选择 NEF 压缩类型（无失真压缩／压缩／未压缩），保存到 `WL-NEF.CFG` | [文档](docs/nef-compression.md)，12/14 位下三个选项已有实机确认 |
| `gyro-evr` | 陀螺仪电子防抖：录像时打开电子减震即生效，修正偏航、俯仰、滚转，与镜头 VR 协同；自定义菜单选标准 / 增强 / 原厂裁切 / 关闭 | [文档](docs/gyro-evr.md) |
| `3d-tracking` | 3D 跟踪：按 OK 或半按快门开始的跟踪，识别到人物或动物后像触摸跟踪一样转为主体识别（细框），半按时也有效；照片拍摄菜单里选关闭 / 开启，默认关闭；**需要把 AF 区域模式设为"自动区域 AF（人物）"或"（动物）"** | [文档](docs/3d-tracking.md)，研究模块已实机验证，固件版待实机确认 |
| `af-frame-colour` | 对焦框颜色改为类似尼康 EXPEED 7 机型（Z9、Z8、Z6III 等）的风格：跟踪框和人物 / 动物框平时白色，半按对上绿色、没对上红色，AF-S 和 AF-C 相同；录像模式的人物 / 动物框为白色；AF-C 普通自动区域框对上时绿色；其他框不变；照片拍摄菜单里可选开启 / 关闭（默认开启） | [文档](docs/af-frame-colour.md)，待实机确认 |
| `focal-length` | 照片取景对所有 CPU 镜头显示当前焦距（原厂只对电动变焦镜头显示），常开 | [文档](docs/focal-length.md)，已有实机确认 |

¹ `wifi-5ghz` 只改无线国家请求，不写整机销售地区或 NVRAM。原本可用 2.4 GHz 第 12、13 信道的机身可能无法再连接这些信道（推断，未实测）。它不保证相机自身的 5 GHz 热点，也不保证提速；有效信道与功率需符合使用地点的规定。

| 预设 | 功能 | 说明 |

| `nef-uncompressed` | 构建时把 NEF 固定为未压缩 | [文档](docs/nef-compression.md)，已有实机确认 |

## 快速开始

### 准备原厂固件

固件需要自行准备，仓库不附带原厂固件，也不附带修改后的升级包。打包工具只接受下面这个原厂文件：

| 项目 | 值 |
| --- | --- |
| 相机 / 固件 | Nikon Z30 / C 1.20 |
| 文件 | `Z_30_0120.bin`，34,496,798 字节 |
| SHA-256 | `1a5449ef505f1f347ed4e066a6a3f588ea542240680e83f4ebcae3b16da3434a` |

### 图形界面（Windows，推荐）

每一步的截图和常见问题见 **[图形界面打包教程](docs/gui-tutorial.md)**。

1. 从 [Releases](https://github.com/WonderLantern/wonder-lantern-z30/releases/latest) 下载 `WonderLanternZ30-windows-x64.zip`，**完整解压**后再运行。
2. 把 `Z_30_0120.bin` 放进解压后的文件夹，或在程序里手动选择。
3. 打开 `WonderLanternZ30.exe`，等待固件校验通过。界面可切换中文或英文、深色或浅色。
4. **第一次：打包加载器固件。** 点“打包加载器 EG”，把 `output/card` 里的 `EG209020.BIN` 刷进相机（设定菜单 → 固件版本）。先不放卡文件，确认相机和原厂一样、固件版本页正常。
5. **打包功能卡文件。** “加载器文件夹”会自动指向刚才的文件夹；勾选功能，点“打包卡文件”，把生成的 `Z30` 文件夹复制到存储卡根目录，重启相机。
6. **以后换功能或更新版本：** 用新版程序、同一个加载器文件夹重新打包卡文件（先移走旧的 `Z30/WL.PATCH`），替换卡上的文件即可，不用重刷。程序提示需要更新加载器时，才重复第 4 步。

程序没有代码签名，Windows SmartScreen 可能提示风险，可以先核对 Release 页面列出的 SHA-256。程序需要 Windows 10/11 自带的 Microsoft Edge WebView2 运行时。其他系统可以运行 `python patch_gui.py`，或改用命令行。

### 命令行

需要 Python **3.10+** 和完整源码。以下命令在项目根目录运行（PowerShell）：

```powershell
python -m pip install '.[sound]'
python patch.py full --card --source "Z_30_0120.bin" --output "output/card"
```

- 生成 `output/card/EG209020.BIN`（加载器固件，刷一次）和 `output/card/Z30/WL.PATCH`（复制到卡上）。
- 以后换功能，在同一个目录加 `--patch-only`，只按已刷的加载器生成新卡文件（先移走旧的 `Z30/WL.PATCH`）：

```powershell
python patch.py liveview-dual m900 mtp-fast --card --patch-only --source "Z_30_0120.bin" --output "output/card"
```

- `.[sound]` 安装 Keystone 汇编器。
- 省略预设时会显示多选菜单：编号 1–19 依次是 `full`、上表十六项和两个可选预设；直接回车选 `full`。多个预设用空格分隔，重复的功能只应用一次。
- `tools/build_card.py` 提供同样的功能和几个额外选项，例如 `--menu-tab`（扩展菜单放到菜单左侧第 8 个标签）和 `--no-banner`（去掉取景就绪提示）。
- **macOS：** 如果安装后报 `fail to load the dynamic library`，在构建用的 Python 环境里执行：

```bash
brew install keystone
ln -s "$(brew --prefix keystone)/lib/libkeystone.dylib" "$(python -c 'import sysconfig; print(sysconfig.get_path("purelib"))')/keystone/libkeystone.dylib"
```

更详细的步骤和常见错误见[离线构建指引](PATCH_GUIDE.md)。

### 打包结果

| 文件 | 用途 |
| --- | --- |
| `EG209020.BIN` | 加载器固件，独立 EG 模块（不是重新封装的 `Z_30_0120.bin`），刷进相机一次 |
| `EG209020.json` | 加载器的构建报告：摘要、加载器身份和能力；以后用 `--patch-only` 打包卡文件时要用到，和 BIN 放在一起 |
| `Z30/WL.PATCH` | 功能卡文件，复制到存储卡根目录的 `Z30` 文件夹 |

- 打包工具会先校验原厂包的大小和 SHA-256，内部解码并检查各级 CRC，再逐项核对原字节、边界和不重叠条件。
- 它不修改输入，也拒绝覆盖已有输出。
- 打包完成只表示本地构建成功，不代表所有机身行为都已验证。

实现细节见[构建说明](docs/build.md)。

### 不用卡：整体刷入（开发者）

命令行省略 `--card` 时，功能直接写进一个完整的 EG（`python patch.py full --source "Z_30_0120.bin" --output "output/EG209020.BIN"`）。这种方式每换一次功能都要重刷，出问题也不能拔卡恢复，只保留给开发和对照测试；图形界面不提供。

## 使用说明

### 菜单与语言

- **菜单入口：** 新功能集中在 **设定菜单 → 自定义菜单**（繁体“自訂選單”，英文 `Extensions`）；只构建声音时入口叫“快门声音”。打包时选 `--menu-tab` 则改为菜单左侧第 8 个标签（灯笼图标）。
- **根页：** 第一行是“状态”（卡文件是否加载、版本、功能数、设置是否保存），下面按用途分类，各功能页在分类页里（[说明](docs/menu-framework.md#根页分类2026-11-25)）。
- **直达行：** 照片画幅、照片高光显示和日期水印也列在照片拍摄菜单末尾，视频码率列在视频拍摄菜单末尾，在列表第一行按一次上键即可到达。直达行右侧固定显示 `--`。这些直达行目前只有 QEMU 验证。
- **语言：** 菜单跟随原厂 **语言 (Language)** 设置，显示简体中文、繁体中文或英文；其他语言显示英文。
- **补字：** 原厂中文字库只有菜单用字。加载器固件为原厂中文字体补上全部可打印 ASCII、中文标签用到的缺字、GB2312 一级字和 Big5 常用字。字形由 Noto Sans CJK 转换而来（SIL OFL 1.1）。补字不提供任意中文输入。
- **固件版本页：** 加载器固件在 设定 → 固件版本 页显示项目名和版权两行，不插卡也显示。

### 自定义快门声音

把声音放在 SD 卡上：

```text
SD 卡根目录/
├─ SHUTTER.WAV
└─ SHUTTER/
   ├─ 1.WAV  …  4.WAV
```

- **格式：** 8000 Hz、单声道、16 位有符号 PCM，非空且最长 1.08 秒，标准 44 字节 WAV 头。可以用 `python tools/prepare_wav.py input.wav SHUTTER.WAV` 转换。
- **触发：** 需要同时开启原厂**静音拍摄**，在静音拍照时播放；录像和非静音拍照不触发。
- **记忆：** 选择和开关会保存到卡根目录的 `WL-SOUND.CFG`，重启后自动恢复。

详见[声音说明](docs/shutter-sound.md)。

### 视频码率与慢动作

在 **自定义菜单 → 视频码率** 中选择档位，默认“高质量”，保存在 `WL-VIDEO.CFG`。单位 Mbps，格式为“最大 / 平均”：

| 高画质模式 | 原厂 | 均衡 | 高质量（默认） |
| --- | --- | --- | --- |
| 4K 30p、25p、24p | 144 / 120 | 168 / 140 | 200 / 168 |
| 1080p 60p、50p | 56 / 48 | 84 / 70 | 108 / 90 |
| 1080p 30p、25p、24p | 28 / 24 | 48 / 40 | 72 / 60 |

- 慢动作录制上限从 3 分钟延长到 25 分钟：FAT32 最多分 8 个文件，exFAT 用单个文件。
- 其他模式的码率、帧率和 125 分钟上限保持原厂值。
- “原厂”档只恢复码率，不撤销慢动作扩展。

### 其他功能

- **视频方向**：开始录制时锁定 0°、90°、180° 或 270°，只写方向元数据，不旋转像素（[文档](docs/video-rotation.md)）。
- **照片画幅**：遮幅强度约 50%，选“关闭”即恢复原厂画幅（[文档](docs/aspect-profiles.md)）。
- **日期水印**：默认关闭，只作用于机内生成的 JPEG（[文档](docs/date-stamp.md)）。
