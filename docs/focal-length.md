# 焦距显示（focal-length）

适用 Nikon Z30 C1.20。照片取景对所有 CPU 镜头显示当前焦距；原厂只对电动变焦镜头显示。常开，没有菜单开关。思路来自 WonderLantern/wonder-lantern-z5 的 `docs/PORTRAIT_UI.md` 第 12.4 节。

## 原理

- 焦距更新函数 `0x1032AC3E`：读取 `[0xC2016A68 + 0x37C] = 0xC2016DE4`，单位 0.1 mm；整数毫米用 `"%dmm"`，否则用 `"%d.%dmm"`，写入控件 `0x3B` 的文字。原厂对所有镜头都更新这个值。
- 显示闸门 `0x10326238(widget)`：控件描述表 `0x1073F830`，`dsc = table[0x3B]`；`dsc + 0x2C` 为条目数，`dsc + 0x30` 为条目数组（每项 0x30 字节）。任一条目第 1 字节为 1 时返回 1；只有电动变焦镜头会把它置 1。与 Z 5 的偏移不同（Z 5 为 `+0x28` / `+0x2C`）。
- 补丁在 `0x1032AC58` 调用闸门之前，把条目 0 的显示字节置 1，原厂更新函数随后照常绘制文字。描述符或条目指针不在 RAM 范围内时不写入。其余代码不变。

## 验证

- `tests/test_focal_length.py`（Unicorn，可选依赖）：显示字节被置 1、流程回到原厂分支 `0x1032AC60`；条目指针为空时不写入；单独构建时原厂区域只改动 `0x1032AC58..0x1032AC5F`。
- 实机读数（USB PTP 只读）：普通（非电动变焦）CPU 变焦镜头，16 mm 端 `0xC2016DE4` = 160，50 mm 端 = 500，普通镜头下照常更新。
- 实机：普通 CPU 变焦镜头显示焦距并随变焦变化，未见异常。

## 构建

2026-11-24 起包含在默认 `full` 中，也可单独选择：

```powershell
python patch.py focal-length --source Z_30_0120.bin --output output/EG209020-focal.BIN
```

报告字段 `features.focal_length`。

## 限制

- 常开，没有菜单开关。
- 与 `portrait-ui` 竖版布局的组合、待机唤醒后的显示（Z 5 的已知问题）未逐项实机验证。
- 定焦 CPU 镜头和转接镜头未逐项记录。
