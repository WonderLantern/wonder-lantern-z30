# 自动跟踪框（auto-arm，研究构建选项）

## 作用

照片拍摄、AF 区域模式为"自动区域 AF"时，取景画面空闲就自动进入跟踪模式（按 OK 出现的跟踪框，画面 1），不用按键。半按快门即开始跟踪；配合 3D 跟踪，人脸或动物进入画面时可以转为主体识别。不改任何按键。

照片拍摄菜单新增一行 "Auto tracking box"（Enable / Disable），默认开启，选择保存在存储卡的 `WL-AARM.CFG`。

这是研究构建选项，不是预设：`full` 等预设不受影响，构建结果逐字节不变。用 `tools/build_auto_arm.py` 构建（`full` 去掉 `gyro-evr`，加 SD 模块宿主和 auto-arm），用法见该文件开头。

## 原理

- 模块源码是 `modules/auto_arm/auto_arm.c`，按 `-DREMAP -DDIRECT -DBUILTIN` 编译后嵌入 EG。
- 开机后 IMU 任务第一次成功读取加速度计时，由 `evr_builtin` 的 autostart 复制并启动（`imu_hook` 的 `boot` 方式），之后约每 50 ms 检查一次。
- 条件：界面阶段为 1 或 2，界面状态为 0（i 菜单打开时为 3），照片后端为 1，AF 显示块 `+0x3FD`（`0xC237CBB1`）为 0，AF 区域模式为 6，`0xC237F680`、`0xC237F684`、`0xC237F688` 都为 0。从别的画面回来后多等约 300 ms。
- `+0x3FD` 在照片取景中为 0、录像中为 1；照片后端字在录像中也是 1，所以只靠它排除不了录像。
- 条件满足时调用原厂取景 OK 处理进入跟踪模式的函数 `0x1045A1AE(&0)`。框没出现时约 1.5 s 后再试。
- 约每秒经 get_property 垫片（键 `0x41524D31`）读一次菜单选择。
- 与 `gyro-evr` 共用 IMU 钩子和内置模块单元，两者不能同时构建。

## 为什么不用模拟 OK

SD 模块实测（2026-11-17）：第 6 版合成 OK（从 IMU 任务写输入环）每次都被写入函数接受，但只有约十分之一能让框出现。同时按下松开、按住约 100 ms、每 1.8 s 或每 0.75 s 重试，结果都一样。

直接调用 `0x1045A1AE`：进入画面后等 300 ms 时，7 次中 7 次第一次调用就出现；总计 16 次中 14 次，两次失败都在进入取景后约 100 ms 内。框在调用后 0.05 到 0.29 s 出现，进入画面后约 0.4 s。

## 验证

- 离线：`tests/test_auto_arm.py` 编译模块、构建，并检查报告和冲突规则。
- Unicorn：`research/auto_arm/emulate_builtin.py` 运行构建好的 EG。只在第一次成功读取后启动；照片取景、自动区域 AF 时只调用一次；录像、i 菜单、菜单、单点、宽区域 L、半按、跟踪中、菜单关闭时都不调用；不读写文件。
- 不加 auto-arm 时，`full` 以及去掉 gyro-evr 再加模块宿主的构建，与修改前逐字节相同。
- QEMU：未做，包括 `verify_firmware_update_qemu.py`。
- 实机（Z30 C 1.20，基于 `8715c25`，2026-11-17）：SD 模块版本的结果见上一节；i 菜单、菜单、回放、录像（含自动区域 AF）、单点、宽区域 L 下都不触发，没有死机。内置固件（SHA-256 `8c9a09bcea9bd71b72e1cb4bf71e41280070c7f01d861f87e41378a806e5b941`）安装后实机确认：
  - 开机后不用操作，跟踪框自动出现；从菜单或回放回到取景约 0.4 s 后出现；
  - 半按开始跟踪，跟踪结束后框回来；
  - 照片拍摄菜单有 "Auto tracking box" 行，默认 Enable；选 Disable 后框不再自动出现，改回 Enable 后恢复，关机重开后保持选择；
  - i 菜单、回放、录像（含自动区域 AF）、单点 AF 下都不触发；
  - 开启 3D 跟踪后，跟踪物体时人脸进入画面会转为主体识别（含本分支对 3D 跟踪照片键的修正）；
  - 设定菜单 → 固件版本可以打开，显示 1.20。

## 已知限制与未验证

- 只在照片拍摄、自动区域 AF 下动作；其他 AF 区域模式和录像中不动作。
- 内置版本不写日志。诊断请用 SD 模块版本（`-DDIAG`），日志用 `tools/inspect_auto_arm_log.py` 读取。
- 照片模式开机也会启动（gyro e-VR 只在录像中启动）。出问题时在菜单里关闭，或经 设定菜单 → 固件版本 刷回。
- 从这个构建再做一次正常升级尚未实测。
