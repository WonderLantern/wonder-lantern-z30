# 焦距显示与精确电量:Z30 C 1.20 定位记录

来源思路:WonderLantern/wonder-lantern-z5 的 `docs/PORTRAIT_UI.md` 第 12.4 节。下列地址均来自对原厂 EG 模块的静态反汇编,尚未在机身或 QEMU 里读数验证。

## 精确电量

- 设置菜单"电池信息"页的构建函数:`0x104CE76E`。栈上 0x50 字节缓冲 `sp`,`bl 0x103C7E78(sp)` 填充后,`[sp+0x18]` 以 `"%d%%"`(字符串 `0x104CEB6C`,`adr` 在 `0x104CE7B2`)显示,`[sp+0x14]` 是第二个 `%d`。这与 Z5 的字段布局一致。
- 取值函数 `0x103C7E78` → `0x102364D4`:加锁,从 `0xC236CD78 + 0xCC = 0xC236CE44` 拷 0x50 字节,解锁。
- 因此电池块是 `0xC236CE44`(Z5 为 `0xC2370E44`),**电量百分比 = `0xC236CE5C`(字节/字,0–100),拍摄张数 = `0xC236CE58`**。
- 另一个页面(`0x104724A0`)用的是不同的结构(`0x10450B20` 返回的 0x30 字节,`+0x29` 为数值、`+0x2A` 用于分档),不要与上面混淆。
- 原厂电池图标的绘制(Z5 为 x<80、y 392–430、60×32)在 Z30 的坐标未核对。

## 焦距

- 焦距显示函数 `0x1032AC3E`:值 = `[0xC2016A68 + 0x37C] = 0xC2016DE4`,单位 0.1 mm;整数毫米用 `"%dmm"`,否则 `"%d.%dmm"`(字符串 `0x1032AFD4`/`0x1032AFDC`)。控件号 `0x3B`。
- 显示闸门:控件描述表 `0x1073F830`,`dsc = table[0x3B]`(`0xC18282B0`);`dsc+0x2C`(字节)为条目数,`dsc+0x30` 为条目数组(每项 0x30 字节),判断函数 `0x10326238`。`0x1032AC62` 起还要求 `[dsc+0x30][1] == 1`。Z5 的做法是把这个"显示字节"置 1;Z30 对应 `*(u8 *)([dsc+0x30] + 1) = 1`。
- 与 Z5 的偏移差异:Z5 是 `+0x28` / `+0x2C`,Z30 是 `+0x2C` / `+0x30`。

## 离线验证(已做)

- 用 Unicorn 执行原厂取值函数 `0x102364D4`,源块 `0xC236CE44` 填入 0..0x4F:目标缓冲逐字节一致,`+0x18`=24、`+0x14`=20。确认电池块起点 `0xC236CE44`、百分比偏移 `+0x18`(`0xC236CE5C`)。
- 这只证明"原厂从那里拷、构建函数读 `+0x18`",不证明机身里该处的实际数值。

## 实机读数(cmos-ptp4 构建,0x9FF1 ReadMemory)

- `0xC236CE5C` = 100,机身电池图标 100%,一致。电池块 `+0x1C` = 0x2124(8484),疑为电压 mV;`+0x14` = 0,不是 Z5 那样的拍摄张数,不使用。
- `0xC2016DE4`:普通(非电动变焦)CPU 变焦镜头,16 mm 端读到 160,拧到 50 mm 读到 500(0x1F4),单位 0.1 mm,一致。普通镜头下该值照常更新。
- 未验证:显示字节置 1 后文字是否出现。

## 电量字段更正(2026-11-17,三块电池读数)

- Z30 没有"电池信息"页,`0xC236CE5C`(+0x18)在三块电池上都是 100,**不是**实时电量,不能直接显示。
- `+0x1C`(`0xC236CE60`)随电池变化:满电 8484、部分用过 8259、更低 8152,是电池组电压(mV)。
- 现在的 battery-percent 用这个电压,经典型锂离子单节开路曲线(×2 加 80 mV,使 8484 读 100)分段线性换算成百分比。这是估算:负载下电压会下垂,与原厂内部算法不完全一致,曲线待用实际放电数据校准。

## 原厂电量来源(未找到)

- Z30 的电池块除开头标志、`+0x18`(恒 100)和 `+0x1C`(电压)外为空;没有找到会填入实时百分比的代码。推测 EN-EL25/EN-EL25a 不向机身报告电量,机身只测电压(未证实)。
- 原厂图标按 59/68/77/86 分档的 0–100 值来自 `0x10450B20`,它在本模块里通向空桩 `0x1033FF5E`,实现不可读。
- 原厂三格图标的当前状态可读:控件描述 `0xC1823E40`,14 个条目(每个 0x30 字节)在 `0xC1823BA0`,显示中的条目第 1 字节为 1;条目 0–5 为电池图标,每档两个。`tools/battery_watch.py` 同时记录电压和这个状态。
